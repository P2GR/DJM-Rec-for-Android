## DJM Rec 0.40.0

Download the **release APK** for normal use. The debug APK is for testing. Requires Android 10+
and an ARM64 phone with USB host support.

### What's changed

- Redesigned recorder with accessible setup controls, an input picker, clearer connection guidance,
  smooth three-band waveforms and stereo meters.
- Improved arming, USB format/rate detection, channel selection and background save handling.
- Improved Sets library: search, playback, export/share, rename/delete and track markers.
- Added Settings customization and improved experimental livestreaming/Google sign-in flow.
- Automatic Bugfender mixer diagnostics and crash reports in release and debug builds, with an
  opt-out in Settings. Manual Diagnostics navigation removed.

### Device support

- **Confirmed by the project owner:** DJM-A9 and DJM-750MK2. Their capture profiles are preserved.
- **Experimental:** DJM-V10, V5, S11 and 450. DJM-900NXS2 needs retesting on the current build.
- **New experimental all-in-one recognition/capture defaults:** XDJ-XZ (master USB5/6), XDJ-AZ,
  OPUS-QUAD and OMNIS-DUO (master USB1/2). Compatible USB audio descriptors are required;
  vendor-only layouts are not automatically supported.
- XDJ-RX3 is recognized, but its documented USB setup has no recording input.

### Before your next set

Make a short stereo test recording. Experimental profiles and livestreaming still require hardware
and provider validation. Background recording cannot survive force-stop, reboot or USB loss.

Automatic diagnostics default on and exclude recorded audio. Turning the setting off stops new
diagnostic logs; finish your set, then force-stop and reopen the app to fully stop SDK traffic.
Previously queued reports may upload until the process ends.

Validation: 50 JVM tests and two native regressions passed on the preceding implementation;
release builds run the Android verification workflow. Physical mixer and portal delivery tests
remain outstanding.
